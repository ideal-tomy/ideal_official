# 数が合わないとき、範囲を絞り、原因を書く。

棚卸で差異が出たとき、たいてい「もう一度数えて」で終わります。差異には原因が四つあり、原因ごとに直し方が違います。範囲を絞り、原因を一つ書き、担当を決める順でまとめました。

**棚卸結果　A-03-14
 SKU 4821**

−10
 帳簿 120個　／　現物 110個
この10個は、どこへ行ったのか

棚卸で10個足りない。この結果だけを見ても、何が起きたかは分かりません。盗まれたのか、誤出荷したのか、そもそも入荷していなかったのか。全部あり得ます。

それなのに、多くの現場では原因を特定する前に数を合わせます。帳簿を現物に合わせて、棚卸を終える。その瞬間、原因を辿る手がかりが消えます。

その結果、翌月も、その翌月も、同じ差異が出ます。直し方は三つです。範囲を絞る、原因を一つ書く、担当を決める。順番に書きます。

## 差異が出たら、数を合わせる前に範囲を絞る

原因を特定する手順は決まっています。難しくありません。

1. 最後に一致していた日を探す
 前回の棚卸か、直近で現物を数えた記録。そこまでは合っていたと分かります。

2. そこから今日までの、入荷・出荷・移動の記録を出す
 この期間のどこかでズレています。範囲が決まれば、あとは絞るだけです。

3. 期間の真ん中で、一度数える
 合っていれば後半、合っていなければ前半。これを繰り返すと、数回で日が特定できます。

4. 日が分かってから、その日の伝票を見る
 ここで初めて原因が分かります。そして、そのあとで数を合わせます。

**図2　範囲を半分ずつ絞る**

*30日分あっても、真ん中で数えることを4回繰り返せば、2日ほどの範囲まで絞れます。全期間の伝票を一枚ずつ見る必要はありません。数えるのは、その品番だけで構いません。*

この方法は、差異が大きい品番だけに使ってください。全品番でやると終わりません。金額の大きい上位の品番から順に見ていくのが現実的です。

## 原因を一つ書く。分からなければ「不明」と書いてよい

- **入荷でズレた（受入）**：
 納品書どおりに登録して、実際には数えていない。相手の出荷ミスが、そのまま自社の在庫差異になります。入荷の時点で数えていれば、その場で相手に言えます。
- **出荷でズレた（ピッキング）**：
 似た品番を取り違えた、数を多く入れた。この場合、どこかのお客さまには多く届いています。差異が二か所で出ているはずです。
- **移動でズレた（ロケーション）**：
 棚を移したが記録していない。在庫はあるので、探せば出てきます。別のロケーションで逆に増えていることが多いです。
- **まだ記録が追いついていない（時差）**：
 現物は動いたが、システムへの反映が翌日になっている。これは差異ではなく、数えた時点が違うだけです。
四つ目が多く、見落とされやすいものです。そして厄介なことに、これを知っていると「たぶん時差でしょう」で全部片づけたくなります。そうなると、本当の誤出荷まで埋もれます。

**図1　結果は一つ、原因は四つ**

*右から左へ遡ります。同じ「10個足りない」でも、入荷の運用を直すのか、ピッキングの照合を増やすのか、数える時点をそろえるのかで、やることがまったく違います。原因を分けずに「気をつけよう」と言っても、何も変わりません。*

差異が出るたびに現場を責めると、差異は減りません。報告されなくなるだけです。数が合わないと分かった時点で、こっそり帳簿を合わせる。誰にも言わない。そうすれば怒られないからです。そして、その瞬間に原因を追う手がかりが消えます。

差異が出たときに聞くべきなのは「誰がやったか」ではなく「どこで起きたか」です。原因の欄に「不明」と書いていい、と決めておくのも同じ理由です。埋めさせようとすると、それらしい原因が書かれるようになって、また分からなくなります。

### 差異は、決算に出てきます

帳簿より現物が少なければ、その分は棚卸減耗として費用になります。金額の大きい品番であれば、決算の数字にそのまま出ます。誤出荷であれば、再送の費用と、お客さまの信用も一緒に減ります。管理にかける費用と比べる相手は、この損失のほうです。

とはいえ、原因を追う時間を人でまかなうと、毎月かかり続ける固定費が増えます。差異は毎月出るので、人を増やせばその人はずっと必要になります。仕組みは、入れるときにまとまった費用がかかりますが、追う時間そのものを短くします。

### 入れる前に、三か月ぶんの内訳を出してください

- 棚卸の差異表に「原因」の列を足す。四つのどれかを書くだけ

- 分からないものは「不明」と書く。埋めなくていい

- 三か月たまったら、どれが多いかを見る

入荷が多いのか、時差が多いのかで、入れるものが変わります。内訳を知らないまま入れると、多い原因に効かないものを買うことになります。

## 誰の職務として置くか決める

営業倉庫の場合は、法令で担当が決まっています。

### 倉庫業法　倉庫管理主任者

倉庫業者は、倉庫ごとに倉庫管理主任者を選任しなければならないとされています（倉庫業法第11条）。業務は大きく二つです。

- 倉庫の施設の管理（火災の防止など、建物や設備の側）

- 倉庫管理業務の適正な運営の確保（保管や荷役の側）

在庫数量の管理は、後者に含まれます。差異の管理は現場の裁量ではなく、選任された人の職務として整理されています。

選任の要件は、倉庫管理業務に3年以上、または指導監督の立場で2年以上の実務経験。実務経験がない場合は、国土交通大臣の定める講習を修了することで要件を満たせます。試験はありません。

[出典　倉庫業法　倉庫管理主任者](https://www.nissokyo.or.jp/seminar_info/)

法令で決まっているから、という話をしたいわけではありません。差異の原因を追う仕事を、誰の職務として置いているかが大事です。ここが決まっていないと、差異は「みんなの問題」になって、結局誰も追いません。

## いまの差異表に、原因を書く欄があるか

差異が出たあと、数を合わせる前に何かしているか。この二つが分かれば、どこから手をつけられるかは見当がつきます。決まっていないことがあっても構いません。
