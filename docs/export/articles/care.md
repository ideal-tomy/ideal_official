# 記録がずれる理由と、その残し方。

運営指導で見られるのは、書類の量ではなく、書類どうしの食い違いです。食い違うのは、その日のうちに書けていないからです。その場で残す、五つを突き合わせる、運営指導の前に揃える、の順でまとめました。

- **ケアプラン**：何をする計画になっているか
- **介護記録**：実際に何をしたか
- **勤務表**：そのとき誰がいたか
- **加算の資料**：算定の要件を満たしているか
- **請求内容**：いくら請求したか
この五つが、同じ出来事を別の角度から書いたものになっているかを見られます。

上の五つは、同じ出来事を別の角度から書いたものです。運営指導では、そろっているかより、互いに合っているかを見られます。直し方は三つです。その場で残す、五つを突き合わせる、運営指導の前に揃える。順番に書きます。

## その日の記録を、その場で残す

職員が手を抜いているから食い違うのではありません。その日のうちに書けていないからです。

訪問から戻って、次の訪問に出て、夕方に事務所へ戻ってから一日分をまとめて書く。この流れだと、時刻は記憶で書くことになります。何時に着いたか、どれくらいいたか。少しずつずれます。

そして、ずれたまま何か月も積み上がったものが、運営指導で突き合わせられます。直すには、書く場所を現場に戻すしかありません。あとから正確に思い出すのは、誰にもできません。

記録が本当に効くのは、監査の日だけではありません。利用者やご家族から「あの日、来てもらえなかった」「そんな説明は受けていない」と言われることがあります。そのとき、やったことを示せるのは記録だけです。職員本人の記憶では、証明になりません。

記録が薄いと、いちばん困るのは現場の職員です。

その場で残せる形にすることは、事務作業を減らす話であると同時に、職員を守る話でもあります。事務所に戻ってから思い出して書いた記録は、書いた本人も自信を持てません。自信を持てない記録は、いざというときに使えません。

## その場で残す形にすると、時刻がずれません

現場で声に出したものが、そのまま記録の形になります。時刻は自動で入るので、記憶で書く必要がなくなります。

現場のスタッフ、事務所の管理、医療との連携。三つの画面がつながっているので、片方で入れたものが、もう片方にどう出るかまでご覧いただけます。

パソコンのChromeでお試しください。まず、最初の画面のマイク（または文字入力）から始めてください。新しい画面が開きます。

[記録の画面を動かしてみる](https://kaigo-operation-demo.vercel.app/)

こちらで用意した利用者情報で動きます。3分ほどで終わります ／ 登録は要りません。

 声に出したものを記録の形にする部分は、本物のAIではなく、あらかじめ用意した動きでお見せしています。実際にAIで動かしたところは、お打ち合わせのときにご覧いただけます。

## 五つの書類が、同じ出来事を指しているか見る

指摘につながるのは、書類が足りない場合だけではありません。そろっていても、書類どうしの内容が合っていないと、そこが指摘の対象になります。

突き合わせられるのは、上の五つです。ケアプラン、介護記録、勤務表、加算の資料、請求内容。どれか一つでもずれていると、サービスの実態や請求の根拠を説明できなくなります。

実際に指摘されているのは、だいたいこのあたりです。

- 勤務表 と 介護記録
 記録に書かれた時刻に、その職員が勤務していないことになっている。あとから書いたときに起きます。

- ケアプラン と 介護記録
 計画にない支援が記録に入っている。または、計画にある支援が記録に出てこない。

- 加算の資料 と 介護記録
 加算の要件になっている行為が、記録から確認できない。人の要件を満たしているだけでは算定できません。

- 介護記録 と 請求内容
 提供した時間と、請求した区分が合っていない。

- 報告の間隔
 訪問介護では、サービス提供責任者への報告を数日分まとめて行っていた例が多く指摘されています。

**図1　同じ出来事なのに、書類ごとに時刻がずれる**

*同じ訪問なのに、勤務表と記録で位置がずれています。あとから思い出して書くと、この幅が生まれます。指摘されるのは記録が少ないことではなく、この幅を説明できないことです。*

月に一度、上の五つを横に並べて見るだけで足ります。全部を読み直す必要はありません。時刻、支援内容、加算、請求区分が、同じ訪問を指しているかだけ確認してください。

## 運営指導の前に揃える

通知が来てから当日まで1〜2週間です。この期間にできるのは、そろえることと、確認することだけです。記録そのものは、もう書き終わっています。対策は、通知が来る前にしかできません。三年に一度の行事のために準備するのではなく、ふだんの記録が説明できる状態になっているか。見るのはそこだけです。

### 運営指導は、こういう流れで行われます

- 2022年度から、実地指導は「運営指導」という名称になりました。オンラインでも行われます

- 原則3年に1回。新しく指定を受けた事業所は、おおむね1年以内に初回があります

- 通知は1〜2週間前に文書で届きます。日時と、当日に確認する書類の一覧が入っています

- 当日は書類の確認と面談で、半日から1日

- 結果は1〜2週間後に文書で届き、改善報告は30日以内に提出します

- 指摘は、改善指導、改善勧告、改善命令、指定取消の順で重くなります

確認する項目と文書については、厚生労働省が「標準確認項目」「標準確認文書」として公開しています。当日にどこを見るかは、事前に調べられる形になっています。

[出典　厚労省　標準確認項目（解説）](https://kaigo-sozai.com/unei-shido-hisshu-shorui-matome/)

### あとから書類を作る、日付を書き換える

通知が届いてから、足りない記録をあとで作る。日付や内容を書き換える。これがいちばん危険です。

虚偽の記録や改ざんと判断されると、運営指導から監査に移ります。監査は、何らかの基準違反や不正請求の疑いがある場合に行われるもので、運営指導とは性格が違います。行政処分につながることもあります。

記録が足りないこと自体は、指導を受けて改善すれば済みます。ただ、取りつくろったことが分かった場合は、そこで終わりません。足りないものは足りないまま出して、改善報告で直す。これがいちばん軽く済みます。

### 返還は、五年さかのぼります

加算の算定が要件を満たしていなかった場合、返還の対象は最大で五年さかのぼります。指摘されるのは一つの月でも、同じやり方を続けていれば、その前も同じです。記録の不備は「今月の話」ではなく、同じ書き方を何年続けてきたか、の話になります。

**図2　指摘されるのは一件でも、返すのは五年分**

*指摘されるのは一つの月でも、同じやり方を続けていれば、その前も同じです。返す金額が数百万円から数千万円になった例があります。*

### 記録を厚くするなら、人ではなく仕組みを足す

記録を厚くしようとしたとき、方法は二つしかありません。人を増やすか、仕組みを入れるかです。人を増やすのは確実ですが、人件費は毎月かかり、業務が落ち着いても下がりません。追加の固定費として、ずっと残ります。

仕組みは逆です。入れるときにまとまった費用がかかりますが、そのあとの毎月の負担は、職員を一人増やすよりかなり小さくなります。比べる相手は、「入れる費用」と「今のまま何もしない費用」ではありません。「入れる費用」と「人を増やし続ける費用」です。

介護の報酬は決まっています。固定費を上げる方向の対策は長く続きません。先に決めておくことがあります。紙をやめるのか残すのか。記録をどこから書き始めるのか。ここが決まらないまま入れると、いまのやり方の上に入力作業が乗るだけになって、固定費だけが増えます。

運用を決めてから入れれば、記録の時間が減り、往復の確認が減り、職員が続けやすくなります。

## 記録を誰がいつ書いているか、一度確認する

前回いつ運営指導を受けたか。今の記録を誰がいつ書いているか。この二つが分かれば、どこを直せばいいかは見えてきます。確認項目は公開されているので、月に一度、そこに載っている書類を見ておくだけで足ります。決まっていないことがあっても構いません。
