# 医療・介護向け 記事（作り直し版）

## 何のための記事か

**運営指導で何を見られるのかを教える記事。**

ソフトの話は主題にしない。見られるのは書類の量ではなく、書類どうしの食い違い。
デモは、食い違いが起きる原因（あとから書いている）の部分だけで出す。

## 記事の題

運営指導で見られるのは、記録の量ではありません。

## 相手

- 介護施設、訪問看護、訪問診療、障害福祉サービスの経営者、施設長、管理者
- 運営指導の通知が来ると慌てて書類を集めている
- 記録は取っているが、それで足りているのか分からない

## 記事の形

**五つの書類を突き合わせて、どこが食い違うと指摘になるかを見せる形。**

建設の時間順、製造の型を教えて分解、飲食のもめごと三つとは別の形。

```
1. 何を見られるかは、実は公開されている
2. 見られるのは量ではなく、書類どうしの食い違い
3. 食い違いが起きる五つの組み合わせ
4. なぜ食い違うのか
5. 【デモ】その場で残す形にする
6. いちばんやってはいけないこと
7. 返還は五年さかのぼる
8. 通知が来てからでは間に合わない
9. 記録は、職員を守るためにある
10. 相談
```

## 教える中身

### 運営指導の基本

- 2022年度から「実地指導」は「運営指導」に名称が変わった。オンラインでも実施される
- 原則3年に1回。新規指定後はおおむね1年以内に初回
- 通知は1〜2週間前に文書で届く。日時と確認書類の一覧が入っている
- 当日は書類の提示と面談。半日から1日
- 結果通知は1〜2週間後。改善報告は30日以内
- 段階は 改善指導 → 改善勧告 → 改善命令 → 指定取消
- **加算の返還は最大5年さかのぼる**

出典: https://kaigo-sozai.com/unei-shido-hisshu-shorui-matome/

### 何を見られるかは公開されている

厚生労働省が「標準確認項目」「標準確認文書」を公開している。
何を見られるかは事前に分かる。慌てて集める必要はない。

出典: https://kaname-law.com/care-media/administrative-response/on-the-spot-guidance/

### 指摘につながるのは、書類の不足だけではない

ケアプラン、介護記録、勤務表、加算の資料、請求内容。
**この五つの間に矛盾があると、サービスの実態や請求の根拠を説明できず、指摘や返還につながる。**

出典: https://www.fc-soft.jp/media/useful_info/a106

### 訪問介護でよくある指摘

- サービス提供責任者への報告を数日分まとめて行っていた
- 記録が不十分だった
- 人材の要件を満たしているだけでは加算は算定できない

出典: https://care-wing.jp/column/jittishido/

### いちばんやってはいけないこと

記録の不足を隠すために、あとから書類を作る。日付や内容を書き換える。
**虚偽の記録や改ざんと判断されると、運営指導から監査に移り、行政処分につながる。**

出典: https://www.fc-soft.jp/media/useful_info/a106

### 返還の規模

指摘を受けて数百万円から数千万円の返還を求められた例がある。

出典: https://caretasukeru.com/business-operations/management-guidance-on-site/468/

## いちばん伝えたいこと

**記録は、行政のためではなく、職員を守るために取る。**

「やっていない」と言われたときに、やったことを示せるのは記録だけ。
記録が薄いと、いちばん困るのは現場の職員本人。

## 図解（2つ）

**図1　同じ出来事なのに、書類ごとに時刻がずれている**
勤務表と記録の二本の時間軸を上下に並べて、ずれの幅を色で示す。
形は「同じ出来事の位置がずれている」。

**図2　返還は五年さかのぼる**
今日から過去に向かって帯が伸びる。一か月分のつもりが五年分になる。
形は「さかのぼる帯の長さ」。

建設・製造・飲食で使った形（流れの太さ／道すじの本数／空欄から出る線／層の厚み／
問いの大きさ／繰り返しの回数／時間軸上の連鎖）とは重ならない。

## 正直に書くこと

声に出したものを記録の形にする部分は、本物のAIではなく、あらかじめ用意した動きで見せている。

## 書かないこと

- ICT、DX
- 補助金を主題にすること
- 記録時間が何%減ったという他社の数字
- 人を減らせるという書き方
