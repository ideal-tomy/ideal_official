## 1. 運送：判定できる時期のコックピット

### 記事の核

改善基準告示は、基準ごとに「守れているかが分かる時期」が違う。  
その場で分かる超過と、月末まで分からない超過が、同じ運行の中に同時に走っている。

### デモで証明すること

> サンプルの乗務記録を開くと、日次はまだ余裕でも、月拘束だけが赤に近づく。判定できる日時が基準ごとに違う、と一目で分かる。

### 対象ユーザー

- Primary: 中小の一般貨物運送事業者の運行管理者
- Secondary: 経営者（管理の見え方を確認したい人）
- シーン: 記事を読んだ直後、2週間分のサンプルで試す

### Must

- サンプルの1人・約2週間分の乗務記録で動く（登録不要）
- 時間帯の上に、次が「判定可能な日時」で点灯する
  - 連続運転 4時間
  - 1日の拘束
  - 運転時間（2日平均）
  - 運転時間（2週平均）
  - 1か月の拘束
- サンプル運行を1本足す操作で、日次は余裕・月次だけ逼迫、が起きる
- 「判定そのものは決まったルールで計算しています。AIではありません」を画面上に出す
- 最初の一手: 「まず、サンプルの2週を開いて、赤い点灯がいつ付くかを見てください」

### Should

- 判定できない期間はグレー（まだ点灯しない）と明示する
- 点呼・運転日報の保存1年への一言リンク（記事の出典へ）

### Won't

- 配車最適化
- 罰則・処分日車数のシミュレーション
- 全社デジタコ基盤・リアルタイムGPS連携
- 「AIが自動で管理します」という文言

### AIの位置（任意）

- 判定ロジックはルール固定
- AIを使うなら運転日報・点呼記録の読み取り（写真/PDF → 時刻）だけ
- Core: Document Text Ingest がある場合のみ。無くてもサンプルだけで完走できること

### 記事への差し込み位置

「判定できる時期が、基準ごとに違う」の説明（階段の図）の直後。

```
DEMO SLOT (logistics) — 未実装
まず、サンプルの2週を開いて、赤い点灯がいつ付くかを見てください。
```

### 受け入れの目安

- [ ] デモリンクを消しても記事単体で読む価値が残る（記事側）
- [ ] 3分・登録不要で「時期が違う」が伝わる
- [ ] ルール計算であることが明示されている
- [ ] iPhone 370px で崩れない

## 2. 倉庫：差異の原因分けワークベンチ

### 記事の核

同じ「10個足りない」でも原因は四つ（入荷／出荷／移動／時差）。  
数を合わせる前に、いつズレたかを特定する。先に合わせると手がかりが消える。

### デモで証明すること

> 「数を合わせる」を選ぶと手がかりが消える。「いつズレたかを絞る」を選ぶと四つの枝に分かれ、時差なら「これは差異ではない」と分かる。

### 対象ユーザー

- Primary: 営業倉庫・自社倉庫の責任者
- Secondary: 経営者（差異の扱い方針を決めたい人）
- シーン: 記事を読んだ直後、サンプル棚卸で試す

### Must

- サンプルの入出荷・移動ログと棚卸結果で動く（登録不要）
- 「10個足りない」から入荷／出荷／移動／時差の4枝が見える
- ユーザーが「数を合わせる」か「いつズレたかを絞る」かを選ぶ
- 範囲を半分ずつ絞る操作（記事の図2）
- 時差を選ぶと「これは差異ではない」と出る
- 「分け方そのものは決まった手順です。AIではありません」を出す（分類下書きにAIを使う場合は、その部分だけ正直に書く）
- 最初の一手: 「まず、10個足りない行を開き、数を合わせる前に原因の枝を選んでください」

### Should

- 「原因不明」を選べること（記事の「不明と書いていい」）
- 倉庫管理主任者の役割への一言（記事の出典へ）

### Won't

- WMS導入デモ
- 在庫精度「99.9%」などの他社数字
- 現場のミス糾弾UI
- 全倉庫のリアルタイム在庫同期

### AIの位置（任意）

- 原因分けの手順はルール固定
- AIを使うなら伝票写真からの数量抽出、または差異メモの4分類下書き
- Core: 任意。無くてもサンプルだけで完走できること

### 記事への差し込み位置

「差異を見つけたら、数を合わせる前にやること」の直後。

```
DEMO SLOT (warehouse) — 未実装
まず、10個足りない行を開き、数を合わせる前に原因の枝を選んでください。
```

### 受け入れの目安

- [ ] デモリンクを消しても記事単体で読む価値が残る
- [ ] 「先に合わせると消える」が操作で体感できる
- [ ] 時差＝差異ではない、が伝わる
- [ ] 3分・登録不要・370px対応

## 3. 実装時の共通手続き

1. デモ側リポジトリにテーマ別要件定義書（本草案を基に確定）を置く
2. AI Demo Standard Definition を複製し、Core接続・Access Mode・Trial・受け入れを埋める
3. AI接続が必要なら `@axeon/ai-demo-core`。体験コードは `VITE_TRIAL_PORTAL_URL` → `/admin/trial` へ誘導
4. 公開URLが決まったら `sites/ideal_official/data/demo-first/portfolio.ts` の `EXTERNAL_DEMO_URLS` に追加
5. `content/articles/logistics.html` / `warehouse.html` の DEMO SLOT コメントを実枠に差し替え
6. `data/articles/index.ts` の `hasDemo` を `true` に更新
