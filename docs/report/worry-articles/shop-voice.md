# 現場の音声を、そのまま入れられない。

ベテランの声を聞き取って、手順書や質問のたたき台を作る——そういう話も、最近はよく聞こえてきます。ここでは、その約束の話はしません。録音した音声を、そのまま外に出せない線について書きます。

## 録音を始める前に、四つを決める

聞き取りを始める前に、次の四つを決めておいてください。順番もこのとおりです。

1. **会社のルールを確認する** … 録音・撮影の社内規定があるか

2. **本人の許可を取る** … 誰の声か、何のために残すか

3. **図面番号や品番は伏せる** … 映り込み・発言の両方

4. **必要以上に残さない** … 社外に出さない

四つが決まっていないまま録音を始めると、あとから止められます。止められたあと、「もう一度最初から」とは言いにくい。ここで止まっている現場が、よくお聞きするパターンです。

## 質問を作る側と、まとめる側では、扱いが違う

手順を聞き取る作業は、大きく二つに分かれます。

**質問を作る**

- 工程の名前と、何を残したいかを伝えるだけで、その工程用の質問が出ます
- 図面も品番も出てきません
- ここは、外に出しても問題になりにくい部分です

**答えをまとめる**

- 話してもらった内容を、主なステップ・急所・理由に整理する部分です
- 現場の情報が入ります
- 伏せてから入れる、または社内で閉じた形で使う必要があります

この二つを一緒くたにしている話は、聞かないほうがいいと思います。「全部AIに任せればいい」という言い方ほど、後から止まりやすい、というお話をよく伺います。

## 録音には、図面番号と取引先名がそのまま入る

製造の現場で録音すると、次のようなものが、意図せず入ります。

- 治具の横に置いてある図面の番号

- 「〇〇商事向けのこの部品」と口に出した取引先名

- 品番を言いながら作業している部分

- 不良の原因を特定するための、社外秘の数値

正直に申し上げますと、**現場の音声をそのまま外のサービスに入れない**——ここは、私たちもはっきり申し上げます。AIを扱う側ですが、順番を飛ばさないでください。

まず伏せる。そのうえで、どこまで入れていいかを社内で決める。この順番が、入れられない線そのものです。

### 伏せたうえで、何が残るか

品番を伏せ、取引先名を切り、図面は写さない——そうすると、残るのは「どこで失敗するか」「新人がよく間違えるところ」といった、**誰が聞いても通用する部分**です。製造記事で書いた急所の話は、ここに当てはまります。

逆に、伏せずにそのまま入れると、契約違反や取引先との約束違反になります。手順書を早く作りたい気持ちは分かりますが、ここで止まるのは、道具のせいではありません。

**図1　録音の中身は、二層に分かれる**

*上の層は、誰に聞かせても問題になりにくい作業の話。下の層は、社外に出してはいけない情報。下の層が入ったままでは、そのまま入れられません。*

## 用意した手順書で、聞き取りの流れを試す

自社の音声を入れずに、流れだけ確かめられます。こちらで用意した手順書と検査記録で動きます。

[聞き取ったものを引き出してみる](https://product-flowideal.vercel.app/manufacturing)

3分ほどで終わります ／ 登録は要りません。

**自社の録音は入れません。** 工程名を選んで、質問の出方と整理の形だけをご覧ください。うちの現場の音声を、いきなり外に出す必要はありません。

店舗の決まりを音声で残したい、という話もあります。レジ横の注意事項や、閉店前の確認——こちらも、お客さまの会話が混ざるとそのままでは出せません。介護の申し送りも同じで、利用者名や服薬内容が一言で入ります。

## 四つを決めたうえで、一工程から始める

全部の工程を、いっぺんに録音しようとすると、止まります。始めるのは、その方が休むと止まる工程——一つだけで足ります。

- 会社のルールを確認した

- 本人の許可を取った

- 伏せるものを決めた

- 残す量を最小にした

この四つが揃っていれば、一時間×二回で一作業ぶんは形になります。まだ四つのどれかが決まっていなくても構いません。決める順番だけ、外から一緒に組み立てることもできます。
