# 社内の文書を全部入れると、見えないはずのものまで出る。

共有フォルダには、営業が見てよいものと、人事だけが見るものと、役員だけが開くものが、同じ木の中に並んでいます。

検索は、この木の閲覧範囲を知りません。全部入れると、画面に出る人には見えないはずの文書まで、答えの材料になります。

## 全員が見てよいフォルダを一つ決める

よく伺うのが、「社内の資料は一か所にまとめてある」という状態です。まとめてあることと、全員が見てよいことは別です。

まず、一番上の共有から、**誰でも開いてよいフォルダを一つ**決めます。規程の公開版、商品の仕様、営業が使うひな形。ここに無いものは、検索の対象にしない。

ここは社内で揃えてください。フォルダ名のきれいさより、入れる人の範囲です。

## 検索は、閲覧の鍵を覚えていない

画面のフォルダは、権限で灰色になります。検索の対象にすると、その灰色が消えます。文書の一文が答えに混ざる。開いてはいけないファイルそのものは出なくても、中身の言い回しが出ることがあります。

正直に申し上げますと、あとから「これは出さないで」と足すより、最初から対象を狭くした方が安全です。出してから消す作業は、残ったコピーを追いきれません。

## 入れてよい文書と、入れてはいけない文書

紙一枚で足ります。

- 入れてよい：全員が読む前提の資料
- 入れない：給与、評価、個別の契約条件、未公開の金額

未公開の金額が営業フォルダに混ざっている会社は珍しくありません。営業フォルダだから全員が見てよい、とは限りません。そのファイルだけ、対象の外へ移します。

社内で話すなら、「社内の文書を全部探せるようにしたい」ではなくて構いません。

「全部入れると、人事と役員の文書まで材料になる。全員が見てよいフォルダが決まっていない」

と言えば足ります。

## 共有の一番上から、一つだけ残す

全部の権限を組み直す必要はありません。検索に渡す対象を、いま決めた一つに限定します。そのフォルダに、公開してよい資料だけを移します。移せないものは、移さない。

**閲覧の範囲が検索に残らない**——この線が先です。探す範囲を広げるのは、範囲が紙に残ってからです。
