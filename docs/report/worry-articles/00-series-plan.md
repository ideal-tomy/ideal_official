# よくある悩み・横断記事シリーズ（10本）

## 位置づけ

ハブ「よくある悩み」は**横断10本のみ**。業界9本（`hubIndustry`）とは別系統。

主題は**知っていても入れられない線**と、**ITなしで明日できる一手**。市場の「DX失敗」「AI導入の目的化」は書かない。

判定は [記事制作ルール.md](../記事制作ルール.md) 1-1どおり。デモリンクを消しても読む価値が残ること。

## 執筆順（新規7）

法令が具体な本から：`receipt-search` → `invoice-fields` → `minutes-names` → `mail-paste` → `folder-rights` → `quote-price` → `time-stamp`

各本は md → 校正 → 専用HTML → `themeArticles` / 目次 / アイコン / sitemap。**次の本に進む前に、デモリンクを消しても読む価値があるか**で止める。

## レイアウト（横断記事共通）

正本の感じは `night-inquiry.html`。**CSSクラス・赤左線・チャット吹き出しはコピーしない。**

- `.wrap.is-theme` 720px、`.col` 620px 中央
- 表紙は全幅の色面。題とメタは表紙の中。仕事の実物が題の前後で画面を占める
- 表紙直後に「約束と実態の食い違い」を1塊
- 図は本文幅いっぱい＋ラベル＋キャプション
