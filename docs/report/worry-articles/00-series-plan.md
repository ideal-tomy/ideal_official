# よくある悩み・横断記事（題の一覧）

ハブ「よくある悩み」に出す題。**ページの骨格・章順はここに書かない。** 1本ずつ、その仕事の物から形を決める。確認は `.cursor/rules/article-is-one-off.mdc`。

公開の正本は `content/articles/t/{slug}.html`。

| slug | ハブ | 題（h1） | 職場 |
|---|---|---|---|
| `night-inquiry` | 夜間に間違えると怖い | 夜間の問い合わせが、間違った答えになる。 | ネットショップ |
| `shop-voice` | 現場の話を出せない | 現場の音声を、そのまま入れられない。 | 製造業 |
| `shift-notice` | 聞いていた時間と違う | 「シフトによる」だけでは、もめは消えない。 | 飲食店 |
| `receipt-search` | 領収書が探せない | PDFをフォルダに入れても、保存したことにはならない。 | 経理 |
| `invoice-fields` | 請求の欄が空 | 請求書を自動で作っても、適格の欄が空だと出せない。 | 経理 |
| `minutes-names` | 議事に名前が残る | 会議の録音を、そのまま文字にできない。 | 事務所 |
| `mail-paste` | メールを貼れない | 返信の下書きは欲しい。本文はそのまま貼れない。 | 営業 |
| `folder-rights` | 見えない文書まで出る | 社内の文書を全部入れると、見えないはずのものまで出る。 | 事務所 |
| `quote-price` | 見積の根拠が残らない | 見積を早く出しても、根拠が残らない。 | 営業・施工 |
| `time-stamp` | 打刻のない日が埋まる | 勤怠を自動にしても、打刻のない日は埋まらない。 | 店舗 |

ハブは横断10本のみ。業界9本の `jamLabel` は悩み列に出さない。

書かない題：「なぜDXが失敗するか」「現場が使わない理由」「24時間の担当者」「社内RAGの始め方」。
