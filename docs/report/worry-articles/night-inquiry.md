# 夜間の問い合わせが、間違った答えになる。

「夜中も自動で答えてくれる仕組み」という話は、もう十分に聞こえてきていると思います。ここでは、その約束の話はしません。夜に届いた問い合わせに、間違った返事を返してしまう怖さと、入れられない線について書きます。

**夜間の問い合わせ
 4件**

22:14

サイズが合わないので返品したいです

23:02

返送の送料はどちらが持つのですか

00:41

いつまでなら交換できますか

02:18

先週注文したもの、まだ届いていません

朝、担当者が開いたとき、上の三件はすでに返信済みでした。返品は可能、送料はお客さま負担、交換は十四日以内、と。

午前中に届いた苦情は、次のとおりです。

> 「返品できると聞いたのに、今朝メールで不可と言われた」
> 「送料がかかるとは聞いていない。表示もなかった」
> 「十四日と言われたが、サイトには七日と書いてあった」

夜中の答えが、そのまま苦情になっています。

## 返品の三つが書いていないと、夜中の答えが当てにならない

よくお聞きするのが、「うちは昼間に人が見ているから、夜はそこまで要らない」という話です。ただ、届く時間帯は選べません。昼間に直した表示が、夜の返信の根拠になっていないと、間違いはそのまま残ります。

通信販売では、返品に関する特約を広告と最終確認画面に表示していない場合、商品を受け取った日から八日以内は、お客さまの送料負担で返品や契約の解除ができます。特定商取引法の第15条の3で決まっています。

表示していれば、その内容が通ります。返品不可でも、七日以内でも、条件つきでも構いません。**書いてあるかどうか**が分かれ目です。

夜中に答える側が見るのは、だいたい次の三つです。

1. 返品できるかどうか

2. できる場合の期間と条件

3. 送料をどちらが負担するか

この三つが商品ページにも最終確認画面にも揃っていないと、夜中は推測で答えるしかありません。推測は、朝には苦情になります。

[出典　消費者庁　特商法　返品ルール](https://www.no-trouble.caa.go.jp/case/mailorder/case01.html)

2022年6月の改正で、注文が確定する直前の画面に六つの契約事項を表示することが義務になりました。商品ページに書いてあっても、最終確認画面に出ていなければ足りません。返品の条件も、ここに含まれます。

## 商品ページと最終確認画面に、返品の三つを書く

明日からできることは、道具を入れることではありません。次の二か所を開いて、三つが揃っているか確認することです。

- 商品ページ … 返品の可否、期間、送料の負担

- 最終確認画面 … 同じ三つが、注文確定の直前に見えるか

フッターだけ、文字が小さすぎる、別ページにしかない——これらは「書いていない」扱いになりやすい状態です。ここは必ずご確認ください。

**図1　夜中に答える根拠は、画面の三か所だけ**

*担当者の記憶でも、前日の口頭説明でもありません。夜中に見られるのは、載っている文字だけです。三か所のどれかに三つが揃っていれば、朝の苦情の大半は消えます。*

四件目の「まだ届いていません」は、返品の話ではありません。発送通知と追跡番号が届いていないだけ、という別の話です。ここも夜中に推測で答えると、到着予定日を間違えて苦情になります。発送した時点で知らせる——これは別の直し方ですが、夜間の怖さは同じです。

## 人が要る質問は、夜中に答えさせない

返品の三つを直しても、全部が自動で済むわけではありません。生地の質感、贈り物の包装、在庫の細かい確認——人がその場で考える必要があるものは残ります。

正直に申し上げますと、夜中にそれらへ答えさせるのがいちばん危ない、というお話をよく伺います。間違った期限や送料を返すより、**答えずに朝まで待つ**ほうが、店としては安全です。

## 答えられないものは、人へ回す

表示と通知を直したうえで、残る分をどう回すかを、画面でご覧いただけます。こちらで用意した商品と案内文で動きます。自社の商品ページを入れる必要はありません。

- お客さまとして質問してみる

- 裏側で何を見て答えたのかを表示する

- よくある質問をまとめた文章を入れて、同じことを試す

[問い合わせの画面を動かしてみる](https://customer-support-demo-lime.vercel.app/)

3分ほどで終わります ／ 登録は要りません。

**答えられない質問は、答えずに人へ回します。** 返品の期限や送料の負担を間違えると、そのまま苦情になります。そこもお試しいただけます。

介護施設でも、「説明は受けていない」と言われる苦情は、案内文が口頭だけのときに起きやすい、という話を伺います。業種は違いますが、夜中に推測で答える怖さは同じです。

## 朝、担当者が謝る前に、三か所を揃える

夜間の問い合わせで消耗するのは、対応のうまさの問題ではありません。答える前から、不利な状態で返信が出ている、という話です。

担当者が「返品不可と言った覚えがない」と言っても、お客さまの画面にはそう届いています。記録は残ります。消耗するのは、店側です。

商品ページと最終確認画面。この二か所に、返品の可否・期間・送料の負担が揃っているか。それだけ、今夜確認していただければ、明日の朝が変わります。まだ不安な点があれば、そのときに残りの話をさせてください。
