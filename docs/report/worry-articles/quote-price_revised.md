# 見積を早く出しても、根拠が残らない。

見積は出ています。品目も金額も入っています。相手から「この単価の根拠は」と聞かれたとき、出せる紙がありません。

単価は、出した人の頭にあります。休むと、同じ一行を説明できません。

## 一品目だけ、単価の出どころを書く

全部の品目を一度に書く必要はありません。よくあるのが、合計だけ合っていて、一行ごとの出どころが無い見積です。

直近の一枚から、金額の大きい一行だけ開きます。その単価は、

- 前回の同じ工事
- 仕入の見積
- 歩掛と人工
- 担当者の判断

のどれですか。一品目だけで構いません。余白か別紙に、出どころを一行書きます。

ここは残しておいてください。次に同じ品目を出すとき、頭ではなく紙を見られます。

## 頭の中の単価では、あとから説明できない

早く出すことと、説明できることは別です。相手が社内で稟議するとき、こちらの担当者が席にいないことがあります。残っているのが合計金額だけだと、電話が戻ってきます。

下請けに出す仕事なら、発注のときに給付の内容と代金の額を書面に残す決まりがあります。見積の段階で単価の出どころが無いと、発注書面を書くときにも同じ空白が残ります。公正取引委員会は、製造委託などをしたときに、内容と金額などを記載した書面を交付するよう定めています。該当する取引かどうかは、取引の形を見て判断します。

## 余白に書くのは、計算式でなくていい

「外壁塗装 一式 480,000。前回2024年10月の同仕様をベース。材料の上がりを1割見た」

この程度で足ります。歩掛の表を添付する必要はありません。出どころの種類が分かれば、次の人が同じ一行を組めます。

社内で話すなら、「見積を自動で出したい」ではなくて構いません。

「見積は出せる。単価の出どころが残っていないので、聞かれたときに説明できない」

と言えば、止まっている線が伝わります。

## 直近の見積一枚から始める

過去五年分を起こす必要はありません。先週出した一枚の、一番高い一行だけ書きます。書けない一行は、単価が頭だけだと分かります。その一行を、次回出す前に仕入か前回工事で確かめます。

**早く出しても、根拠が残らなければ、説明できない見積のままです。** 一品目の出どころが残れば、次の品目も同じ欄で書けます。
