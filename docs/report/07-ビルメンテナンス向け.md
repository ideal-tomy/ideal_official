# ビルメンテナンス向け 記事

## 何のための記事か

**法定点検の期限を、どう管理するかを教える記事。**

システムの話は主題にしない。台帳の作り方は紙でもExcelでもできる。
デモは、棟数が増えたときの話としてだけ出す。

## 記事の題

法定点検が漏れるのは、周期ではなく起点が違うからです。

## 相手

- ビル管理会社、設備管理会社の経営者、管理部門の責任者
- 自社ビルや商業施設を持っている会社の管理担当
- 複数棟を見ている人

## 記事の形

**台帳の列を、一つずつ決めていく実演の形。**

建設の時間順、製造の型を教えて分解、飲食のもめごと三つ、
介護の五書類の突き合わせ、小売の分類軸の入れ替え、保育の逆算とは別の形。

```
1. 一棟に、周期の違う点検がいくつあるか
2. 周期が違うだけなら、まだ管理できる
3. 本当の問題は、起点が違うこと
4. 起点は三種類ある
5. だから台帳に必要な列は五つ
6. 棟が増えると、件数は掛け算になる
7. 【デモ】棟をまたいで見る画面
8. とはいえ、管理のためにお金は出せません
9. 期限は、担当者一人の記憶に載っている
10. 相談
```

## 教える中身

### 建築物衛生法（特定建築物）

- 空気環境測定：2か月以内ごとに1回（年6回）
- ホルムアルデヒド：新築や大規模の修繕等の使用開始後、
  直近の6月1日から9月30日までの間に1回
- 冷却塔・加湿装置・空調機の排水受け：使用開始時と、使用期間中1か月以内ごとに1回点検
- 冷却塔と冷却水の水管：1年以内ごとに1回清掃
- 受水槽・高置水槽：1年以内ごとに1回清掃。清掃作業報告書を作成し保管する
- 特定建築物の届出：使用開始日から1か月以内に保健所へ

出典: https://www.tmiph.metro.tokyo.lg.jp/k_kenchiku/bldg/kijyun/
出典: https://www.mhlw.go.jp/stf/newpage_10747.html

### 消防法

- 機器点検：6か月に1回
- 総合点検：1年に1回
- 報告：特定防火対象物は1年に1回、非特定防火対象物は3年に1回
- **報告の基準日は、その建物（事業所）の管理を開始した日**
- 防火対象物点検：1年に1回
- 届出のオンライン化が進んでいる（2022年10月の名古屋市を皮切りに、
  東京消防庁、大阪市、熊本市などが順次対応）

## いちばん大事な考え方

**漏れる原因は、周期がバラバラだからではない。起点が違うから。**

- 前回の実施日から数えるもの（空気環境測定、貯水槽の清掃）
- 建物の管理を開始した日から数えるもの（消防の報告）
- 年度で決まっているもの（社内の予算や契約）

起点が違うと、カレンダーに「4月にまとめてやる」と置けない。
一度ずれると、そのあとの期限が全部ずれていく。

## 台帳に必要な五つの列

1. 点検の項目
2. 周期
3. 起点（何から数えるか）
4. 根拠（どの法令か）
5. 次回の期限（前回実施日から計算した日）

三つ目の「起点」が抜けている台帳が多い。ここが抜けると、
期限がカレンダーの都合で動いてしまう。

## 図解（2つ）

**図1　起点が違うと、同じカレンダーに置けない**
一本のカレンダーの上に、起点の違う三つの周期を重ねる。刻みの位置がそろわない。
形は「起点のずれた目盛り」。

**図2　棟が増えると、件数は掛け算になる**
1棟あたりの年間件数 × 棟数。格子で面積として見せる。
形は「掛け算の面積」。

これまでに使った形とは重ならない。
