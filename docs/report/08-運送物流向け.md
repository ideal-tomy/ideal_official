# 運送・物流向け 記事

## 何のための記事か

**改善基準告示を、どう管理するかを教える記事。**

この記事にはデモを付けない。運送に当てられるデモが手元にないため、
無理に当てずに、記事として完結させる。相談への導線だけ置く。

## 記事の題

守れているかが分かる時期は、基準ごとに違います。

## 相手

- 中小の一般貨物運送事業者の経営者、運行管理者
- 2024年4月の改正には対応したが、日々の管理が回っていない

## 記事の形

**「いつ判定できるか」で並べ替える形。**

これまでの形（時間順／型を教えて分解／もめごと三つ／五書類の突き合わせ／
分類軸の入れ替え／結果から逆算／台帳の列を決める）とは別。

```
1. 2024年4月に何が変わったか
2. 判定の単位は、五つある
3. 本当の問題は、判定できる時期が違うこと
4. 月末に分かっても、もう戻せない
5. 一運行の中では、三つの基準が同時に走っている
6. 記録は、法令で1年保存が決まっている
7. とはいえ、管理のためにお金は出せません
8. 記録は、運行管理者を守るためにあります
9. 相談
```

## 教える中身

### 改善基準告示（2024年4月1日適用）

トラック運転者について、主なものは次のとおり。

| 項目 | 基準 |
|---|---|
| 1日の拘束時間 | 原則13時間以内、最大15時間 |
| （例外）宿泊を伴う長距離貨物運送 | 1週につき2回まで16時間 |
| 1か月の拘束時間 | 原則284時間以内 |
| 1年の拘束時間 | 原則3,300時間以内 |
| 休息期間 | 継続11時間以上を基本、継続9時間を下回らない |
| 運転時間 | 2日平均で1日9時間以内 |
| 運転時間 | 2週平均で1週44時間以内 |
| 連続運転時間 | 4時間以内 |

2022年12月に改正され、自動車運転の業務には5年の猶予が置かれたため、
適用は2024年4月1日から。

出典: https://www.miyatokyo.or.jp/wp/wp-content/themes/blankslate/2024/pdf/2024_leaflet02.pdf

### いちばん大事な考え方

**判定できる時期が、基準ごとに違う。**

| 基準 | いつ分かるか |
|---|---|
| 連続運転4時間 | その場 |
| 1日の拘束13時間 | その日の終わり |
| 運転時間 2日平均9時間 | 翌日の終わり |
| 運転時間 2週平均44時間 | 2週間後 |
| 1か月の拘束284時間 | 月末 |
| 1年の拘束3,300時間 | 年度末 |

**遅いものほど、気づいたときには手を打てない。**
月末に「284時間を超えていました」と分かっても、その月はもう終わっている。

### 保存が決まっている帳票

貨物自動車運送事業輸送安全規則で、次のものは1年間保存。

- 点呼記録簿（第7条）
- 乗務等の記録／運転日報（第8条）
- 運行記録計の記録（第9条）
- 運行指示書およびその写し（第9条の3）

出典: https://www.naganota.or.jp/cms/wp-content/uploads/2021/06/26.pdf
出典: https://www.mlit.go.jp/jidosha/jidosha_tk2_000162.html

### 点呼で確認すること

酒気帯びの有無だけではない。顔色、呼気の臭い、応答の声の調子も確認する。
平成30年6月1日から、疾病や疲労の状況の確認に「睡眠不足」が加わっている。

2泊3日の運行のように、乗務前も乗務後も対面でできない日は、
電話等で乗務前・乗務後に加えて、途中に少なくとも1回の点呼が必要。

出典: https://www.naganota.or.jp/cms/wp-content/uploads/2021/06/tenko_kaisetu.pdf

## 図解（2つ）

**図1　判定できる時期が、遅い順に並ぶ**
その場・その日・翌日・2週間後・月末・年度末。階段状に遅れていく。
形は「判定時点の階段」。

**図2　一運行の中で、三つの基準が同時に走っている**
一本の運行の帯の上に、拘束時間・連続運転・休息期間の判定が重なる。
形は「重なり」。

これまでに使った形とは重ならない。
