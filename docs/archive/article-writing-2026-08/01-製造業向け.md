# 製造業向け 記事（作り直し版）

## 何のための記事か

**ベテランの作業を、聞き取って書き残す方法を教える記事。**

道具の話は一切しない。紙とペンがあれば明日からできる内容にする。
デモは、聞き取ったものをどこに置いておくかの部分だけで出す。

## 記事の題

ベテランの手順を、聞き取って書き残す方法。

## 相手

- 中堅製造業の社長、製造部長、品質保証の責任者
- 手順書はあるが、読んでも新人が作れない
- ベテランが数年内に抜ける

## 記事の形

**一つの作業を、実際に分解してみせる形。**
建設の時間順とも、飲食の表とも違う。読者が記事を読みながら手を動かせる形にする。

```
1. 手順書はあるのに、読んでも作れない
2. 一行の下に、書かれていない二つの層がある
3. どれが急所かを見分ける三つの条件
4. ベテランに書かせない。話してもらう
5. 聞き方を変えると出てくる
6. 【デモ】聞き取ったものを、どこに置くか
7. 録音するときに守ること
8. 教える人ごとに言葉が違うと、新人が混乱する
9. 全工程でやらない。一作業から
10. 相談
```

## 教える中身

### 作業は三つに分けて書く（TWI-JI の作業分解）

- **主なステップ** … 何をするか
- **急所** … 勘、コツ、巧み。手順書に書かれないもの
- **急所の理由** … なぜそれが急所なのか

いまの手順書には、主なステップしか書かれていないことがほとんど。
だから読んでも作れない。

### 急所かどうかの三つの条件

1. 出来栄え … 仕事の到達点と品質の判断基準が決まるか
2. 安全 … 危ないか、けがの恐れがあるか
3. やりやすさ … 勘やコツの動きが要るか

このどれかに当てはまれば急所。当てはまらなければ、ただの手順。

### ベテランに書かせない

書いてもらおうとすると止まる。話してもらう。聞く側が質問を用意する。

- この作業の目的は何ですか
- 最初に確認することは何ですか
- 作業の大きな流れを三つに分けるとどうなりますか
- 新人がよく間違えるところはどこですか
- やってはいけないことはありますか
- 最後に確認することは何ですか
- この作業でいちばん大事なところはどこですか

**「どうやるんですか」と聞かない。「どこで失敗しますか」と聞く。**
前者では手順しか出てこない。後者からは急所が出てくる。

### 録音・撮影で守ること

- 会社のルールを確認する
- 本人の許可を取る
- 図面番号や品番は伏せる
- 社外に出さない
- **AIにそのまま入れない**

最後の一つは、AIを売る側として必ず書く。書かないと信用されない。

### 教える人によるばらつき

同じ作業を、人によって違う順番・違う言葉で教えると、新人が混乱する。
「Aさんが教えた人はできるが、Bさんが教えた人はミスが多い」が起きる。
手順書は、教え方をそろえるためのもの。

### 文字だけでは足りないところがある

細かい手の動きや持ち方は、文字にしきれない。
写真や動画で補う。ここは正直に書く。

## 図解（2つ）

**図1　手順書の一行の下に、書かれていない二つの層がある**
紙に書かれているのは主なステップだけ。その下に急所と理由の層があって、
それは人の頭の中にしかない。層の厚みで見せる。

**図2　大きな問い一つを、七つの小さな問いに割る**
「全部教えてください」と聞くと何も出てこない。
七つに割ると、それぞれから少しずつ出てくる。分割の形で見せる。

建設で使った形（流れの太さ／道すじの本数／空欄から出る線）とは重ならない。

## 書かないこと

- DX、AI活用、デジタル化といった道具の話を主題にすること
- 「属人化」「形式知化」「暗黙知」といった言葉
- 金額の例（自社の見積もりと誤解される）
- ベテランを否定する書き方
