# 飲食店向け 記事（作り直し版）

## 何のための記事か

**シフトでもめないために、先に決めておくことを教える記事。**

ツールの話は主題にしない。決めごとは紙一枚でできる。
デモは、当日の欠勤の穴埋めという「決めごとでは防げない部分」だけで出す。

## 記事の題

シフトでもめないために、先に決めておく四つのこと。

## 相手

- 何店舗か持っている飲食企業の社長、エリアマネージャー
- 単店の店長
- シフトのことでスタッフともめた経験がある

## 記事の形

**もめごとの実例三つから入って、原因と決めごとに落とす形。**

建設の時間順、製造の「型を教えて分解してみせる」、保育の絞り込みとは別の形にする。

```
1. もめるのは、組み方が下手だからではない
2. もめごと① シフトを減らされた
3. もめごと② 聞いていた時間と違う
4. もめごと③ 休みの希望が通らない
5. だから、先に決めておく四つ
6. 一日八時間を超えるシフトには、別の手続きが要る
7. 決めごとでは防げないのが、当日の欠勤
8. 【デモ】希望を集めて、決めて、伝えるまで
9. 決めごとが効くのは、店長が判断しなくてよくなるから
10. 相談
```

## 教える中身

### 厚生労働省の留意事項

「いわゆる『シフト制』により就業する労働者の適切な雇用管理を行うための留意事項」
（令和4年1月7日、令和8年6月19日改正）

- 労働条件通知書に「シフトによる」とだけ書くのでは足りない
- 対応は二つのどちらか
  1. 労働日ごとの始業・終業時刻を明記する
  2. 原則的な始業・終業時刻を書いたうえで、一定期間分のシフト表を一緒に渡す
- 休日も、具体的な曜日が決まっていなくても「休日の決め方の考え方」を示す必要がある
- 会社の都合で労働日をほとんど入れない、または本人の希望を超える日数を入れると、
  トラブルになりやすいと明記されている

出典: https://www.mhlw.go.jp/content/11200000/001713615.pdf

### 一日八時間を超えるシフト

一日八時間を超えるシフトを組むには、変形労働時間制の導入が必要。
入れていない状態で組むと、超えた分は残業扱いになる。

一週間単位で組む場合は、直前の週末までに決めて本人へ通知する。

出典: https://www.shifop.jp/column/62

### 特例措置対象事業場

飲食店で働く人が十人未満の事業場は、週の法定労働時間が四十四時間。
十人を超えると四十時間になるので、人が増えたときに要注意。

出典: https://jsite.mhlw.go.jp/saga-roudoukyoku/library/saga-roudoukyoku/seido/seido07_17.pdf

### 先に決めておく四つ

1. いつまでに通知するか（期限）
2. 始業・終業をどう書くか（範囲＋シフト表を渡す形）
3. 休日をどう決めるか（考え方）
4. 決まったあとに変えるときのやり方

この四つを労働条件通知書に書いておく。書けば、毎月の判断が要らなくなる。

## いちばん伝えたいこと

**決めごとが効くのは、店長が判断しなくてよくなるから。**

その場で店長が決めると、「あの人だけ優遇されている」が必ず起きる。
先にルールがあれば、店長は運用するだけになる。店長が嫌われずに済む。

決めごとは、スタッフを縛るためではなく、店長を守るためにある。

## 図解（2つ）

**図1　決めていないと、毎月同じ判断が発生する**
月ごとに同じ判断のしるしが並んでいく。先に決めれば、しるしは一回だけ。
形は「繰り返しの回数」。

**図2　確定が遅れると、その先が全部ずれる**
横の時間軸に、締切・調整・確定・通知の点。確定が右にずれると、
仕込みも発注も一緒に右へずれる。形は「時間軸上の連鎖」。

建設・製造で使った形（流れの太さ／道すじの本数／空欄から出る線／層の厚み／問いの大きさ）とは重ならない。

## 正直に書くこと

デモの割り当ては、決まったルールで計算している。AIではない。
