## B01｜Hero

**見出し:** 現場写真の整理から、報告書の作成まで。

**サブ:** 現場で撮影した写真を整理し、日報や工事写真台帳の作成につなげます。

**本文:** 写真を撮る方法や、現在の保存先を大きく変える必要はありません。まずは1現場から、実際の写真を使って試すことができます。

**CTA:** 削減できる時間を試算する / デモを試す

**バッジ:** 実証トライアルは無償 / NDA締結・秘密厳守 / 現在の撮影方法をそのまま利用
